Este ejercicio se pone en práctica:

- La creción de funciones
- La utilización de las funciones map, filter y reduce en listas para generar códigos breves
- La utilización de condicionales
- La cración de clases en python 
- La gestión de errores

Para realizar estas katas se ha utilizado 

- Python 3.13
- functools
- datetime
- math
- Jupyter

En el fichero PY se podrá ver los encunciados de los ejercicios seguidos de sus resultados y de como se ha intentado aboradar el problema individualmente, uno a uno.
Par apoder abarcar cada Kata se ha seguido el siguinete procedimieto:

1) Lectura y comprensión del ejercicio.
2) Organización y esquematización de la idea para resolver la kata.
3)  Una vez organizada la idea diseño del código
4)  Utilización del código y probar posible errores.
5) Correción del código o incorporación de soluciones a posibles errores para que se funcional el código en los posibles excenearios
